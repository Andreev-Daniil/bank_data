# Газпромбанк — Финансовые показатели (2022–2026)

## Описание

Парсер финансовых показателей Газпромбанка с сайта [banki.ru](https://www.banki.ru/banks/ratings/?BANK_ID=2764).

Данные включают:
- Активы
- Капитал
- Чистая прибыль
- Кредитный портфель
- Просроченная задолженность
- Вклады физических лиц
- Место в рейтинге по активам и капиталу

**Период:** с января 2022 года по текущий момент (ежеквартально)

## Файлы данных

| Файл | Описание |
|------|----------|
| `public/data/gazprombank_ratings.json` | Данные в формате JSON |
| `public/data/gazprombank_ratings.csv` | Данные в формате CSV (разделитель `;`) |

## Использование веб-приложения

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```

## Python-скрипт для парсинга

Файл `scraper.py` содержит скрипт для автоматического получения данных с banki.ru.

### Установка зависимостей:
```bash
pip install requests beautifulsoup4 playwright
playwright install chromium
```

### Запуск:
```bash
python scraper.py
```

### Методы получения данных:

1. **Через requests** — попытка получить данные из HTML без JavaScript
2. **Через Playwright** — headless-браузер для рендеринга JavaScript
3. **Через ЦБ РФ API** — прямой запрос к источнику данных

> ⚠️ **Примечание:** Сайт banki.ru загружает данные динамически через JavaScript (React-приложение). 
> Для полного парсинга рекомендуется использовать Playwright или Selenium.

## Источник данных

- **banki.ru** — агрегатор финансовых данных (на основании отчётности ЦБ РФ)
- **ЦБ РФ** (cbr.ru) — первоисточник данных
- **ID банка:** 2764
- **Лицензия:** № 354
