## Описание

## Нормативы достаточности капитала

Расчёт выполняется в соответствии с **Положением ЦБ РФ № 2024-У** и стандартами **Базель III**:

### Формулы

| Норматив | Формула | Базовое значение | Для СЗКО (с надбавкой) |
|----------|---------|-------------------|------------------------|
| **Н1.0** | К / А × 100% | ≥ 8.0% | **≥ 12.5%** (+4.5 п.п.) |
| **Н1.1** | К₁ / А × 100% | ≥ 6.0% | **≥ 9.0%** (+3.0 п.п.) |
| **Н1.2** | К₂ / А × 100% | ≥ 2.0% | **≥ 3.5%** (+1.5 п.п.) |

Где:
- **К** — собственный капитал (основной + дополнительный)
- **К₁** — основной капитал (Common Equity Tier 1)
- **К₂** — дополнительный капитал (Tier 2)
- **А** — активы, взвешенные по уровню риска (RWA)

## Запуск

### Веб-приложение (React + TypeScript)

```bash
# Установка зависимостей
npm install

# Режим разработки
npm run dev

# Сборка для продакшена
npm run build
```

### Python-скрипт

```bash
# Установка зависимостей
pip install requests beautifulsoup4 playwright
playwright install chromium

# Запуск парсинга
python scraper.py
```

## Нормативная база

1. **Положение ЦБ РФ № 646-П** — методика определения собственных средств (капитала) кредитных организаций
2. **Положение ЦБ РФ № 2024-У** — обязательные нормативы и надбавки к нормативам достаточности капитала
3. **Базель III** — международные стандарты достаточности капитала
4. **Указание ЦБ РФ** — перечень системно значимых кредитных организаций

## Источник данных

- **banki.ru** — агрегатор финансовых данных (на основании отчётности ЦБ РФ)
- **ЦБ РФ** (cbr.ru) — первоисточник данных
- Период: январь 2022 — сентябрь 2026 (ежеквартально)

## Примечание

> ⚠️ В данной реализации используется упрощённый расчёт нормативов, где в знаменателе применяются общие активы вместо активов, взвешенных по уровню риска (RWA). Для получения точных значений необходимо обратиться к официальной отчётности кредитных организаций на сайте ЦБ РФ.
